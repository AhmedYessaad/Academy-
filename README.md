# Fluencia Academy — نظام إدارة الأكاديمية

تطبيق ويب عربي متجاوب لإدارة أكاديمية تعليم اللغة الإنجليزية.

## الميزات
- لوحة تحكم ومؤشرات التلاميذ والصفوف والتحصيل المالي.
- تسجيل التلاميذ وتعديلهم وحذفهم، رقم الهاتف، الصف، الرسوم، المدفوع، وملاحظات الدفع.
- إنشاء الصفوف والمجموعات، المستوى، الأستاذ، القاعة، الرسوم، والسعة.
- مراقبة الإيرادات المتوقعة والفعلية والمتبقية ونسبة التحصيل.
- تسجيل دفعات جزئية أو كاملة وحفظ سجل الدفعات.
- برنامج أسبوعي للحصص حسب اليوم والوقت والصف والأستاذ والقاعة، مع فحص تعارض وقت الصف، وطباعة البرنامج.
- نسخة احتياطية JSON واستعادة البيانات.
- واجهة RTL بلون بنفسجي فاتح، تدعم الحاسوب والهاتف، وقابلية التثبيت PWA.

## النشر والتثبيت
1. فك ضغط ZIP.
2. ارفع محتويات المجلد إلى استضافة HTTPS مثل GitHub Pages أو Netlify.
3. افتح الرابط في المتصفح ثم اختر تثبيت التطبيق أو إضافته للشاشة الرئيسية.

## مهم
النسخة الحالية تحفظ البيانات في المتصفح على الجهاز (localStorage)، ولا توفر حسابات دخول أو مزامنة بين عدة أجهزة. خذ نسخة احتياطية بانتظام. للاستخدام متعدد الموظفين أو الوصول من أجهزة مختلفة، يلزم خادم وقاعدة بيانات وتسجيل دخول.
